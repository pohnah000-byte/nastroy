Подключи GitHub

Музыка хранится в твоём репозитории nastroy. Чтобы приложение могло туда сохранять, один раз создай ключ доступа:

  1. Открой github.com → Fine-grained token
  2. Token name: СВОИ, Expiration: максимальный срок
  3. Repository access → Only select repositories → nastroy
  4. Permissions → Contents → Read and write
  5. Нажми Generate token, скопируй ключ и вставь ниже
